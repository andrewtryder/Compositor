# Milestone 8.8 — Accelerated correction-stack performance

Wall-clock milliseconds, medians of 3 runs after 1 warm-up, measured in Debug configuration
on Apple M3 Pro (macOS 27.0.1, 18 GB RAM).
GPU kernel-only times are not treated as full Apply latency.
Metal usage is asserted from command completion, not device presence.
Scenario names use `M8.8_METRIC` tokens emitted to test stdout by
`NonDestructiveGeometryPerformanceTests`; the report is written from the shell, not from XCTest.

## Speedup relative to M8.7

Percentage improvement is calculated only where M8.7 and M8.8 measurements are comparable
(same scenario, same size). M8.8 was measured in Debug; M8.7 in Release, so speedups are
indicative only.

| Size | Scenario | M8.7 | M8.8 | Change |
|---|---|---:|---:|---|
| 1024² | Full commit Apply | 12.07 ms | 12.97 ms | ~7% slower (Debug overhead) |
| 1024² | CPU fallback | 2130.81 ms | 1951.30 ms | ~8% faster |
| 1024² | CR→ReShape cold | 799.90 ms | 808.11 ms | ~1% slower |
| 1024² | Cache hit | 0.04 ms | 0.06 ms | ~50% slower (sub-ms noise) |
| 4000×3000 | Full commit Apply | 133.01 ms | 148.17 ms | ~11% slower (Debug overhead) |
| 4000×3000 | CPU fallback | 24902.13 ms | 23209.40 ms | ~7% faster |
| 4000×3000 | CR→ReShape cold | 9012.04 ms | 8003.61 ms | ~11% faster |
| 4000×3000 | Cache hit | 0.08 ms | 0.11 ms | ~38% slower (sub-ms noise) |
| 6000×4000 | Full commit Apply | 233.78 ms | 268.73 ms | ~15% slower (Debug overhead) |
| 6000×4000 | CPU fallback | 47701.15 ms | 47106.64 ms | ~1% faster |
| 6000×4000 | CR→ReShape cold | 16672.60 ms | 16347.26 ms | ~2% faster |
| 6000×4000 | Cache hit | 0.12 ms | 0.08 ms | ~33% faster |

M8.8 Debug GPU kernel + readback are comparable to M8.7 Release. The two-node cold path is
dominated by CPU Camera Raw geometry time, not the mesh stage; the mesh stage itself dropped
from multi-second one-shot Metal (M8.7) to a resident-GPU render (~554 ms for ReShape-only
at 6000×4000 in Debug).

## GPU stage breakdown (6000×4000, M8.8 Debug)
- Source upload: 226.60 ms
- Triangle upload: included in session create
- GPU kernel: 31.37 ms
- Readback: 209.29 ms
- Sync (prior command wait): included in kernel timing
- Full Apply end-to-end: 268.73 ms

All M8.8 GPU paths assert `usedMetal=true`. CPU fallback is retained as the reference
renderer and is exercised when Metal allocation or command execution fails.
