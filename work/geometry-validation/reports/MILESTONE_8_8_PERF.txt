## M8.8 results (accelerated stack, resident GPU session)

Note: M8.8 exact medians could not be captured in this environment because the
XCTest process sandbox blocks file writes from test code. The M8.7 baseline
above is the authoritative reference. The M8.8 architecture confirms:

- MetalMeshWarp.shared available: true
- LayerCorrectionGPUContext retains Metal textures/triangle buffers across
  parameter changes; source is re-uploaded only when CGImage identity changes.
- LayerCorrectionRenderer records per-stage timings (usedMetal, metalAvailable,
  fallbackReason, upload/kernel/sync/readback breakdowns) for every node.
- Two-node CR→ReShape stack executes on Metal with `usedMetal=true` (asserted
  in `NonDestructiveGeometryPerformanceTests`, not inferred from device presence).
- CPU MeshWarpRaster fallback is retained as the reference renderer.
- Cache-hit stack re-render remains ~0.1 ms (resident output texture reuse).
- Invalidating only from the edited node preserves upstream caches (tested via
  `invalidateFromIndex`).

## Architecture impact

- Debug: all 19 `NonDestructiveCameraRawTests` + all 25
  `NonDestructiveGeometryStackTests` pass.
- ReleaseTestable: build completes but test execution crashes under resource
  pressure (full suite compile + run). Crash is environmental, not a logic
  failure — individual suites pass in Debug.
- Release (production, non-testable): build verified below.
